# Река Арда · DNCH Fishing

Самостоятелна подробна страница за Арда след Огоста. Съдържа три зони, шест вида, 20 примамки, три комплекта, шест фотографии, карта, ограничения, сезонен помощник. Данните са в `arda.json`, уеб страницата в `index.html`. Не променя публикувания гид за Огоста. Снимките запазват автор и лиценз. Редакционните източници не се показват като публична библиография. Важно: егейски кефал е Squalius orpheus, не Squalius cephalus.
