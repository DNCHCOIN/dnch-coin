# Товарене на ремарке

Самостоятелен статичен планировчик за товари. Отваря се без регистрация и без вход.

- Размери в мм, см и м; количества, височина, кг за брой и завъртане.
- Подреждане на нестандартни правоъгълни товари и разрешено стифиране до вътрешната височина.
- 1700 кг на плъзгащ 1-метров участък при равномерно тегло по дължината на товара; резервирана дължина поне общо кг / 1700.
- Палетоместа = резервирани линейни метри × 2,5, по зададеното съотношение 5 палета / 2 м.
- Схема, странични изгледи на стифове, печат/PDF, JSON импорт/експорт и локално автоматично запазване.

## Стартиране

GitHub Pages публикува папката като `/dnch-coin/truck-loader/`. Няма build, зависимости, API ключове или сървър. За локално ползване отворете `index.html` или стартирайте `python -m http.server 8000` в тази папка.

Въведените товари остават в localStorage на конкретния браузър; не се изпращат на сървър. Различните колеги работят с отделни локални данни. За пренасяне на план използвайте JSON файла.

## Ограничения

Алгоритъмът търси добър допустим вариант, без да гарантира глобален минимум. При липса на намерен план не доказва, че подреждането е невъзможно. Стифира се един товар върху един долен, с пълна опора и без надвес. Отметката „Отгоре“ се задава от оператора. Не се проверяват товароносимост на опората, реални точкови натоварвания, осови натоварвания, укрепване и ред на разтоварване. Правилото 1700 кг/л.м. е работно изискване на този планировчик, а не универсално удостоверяване на допустим товар за всяко превозно средство.
