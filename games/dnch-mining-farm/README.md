# DNCH MINING FARM — Android Tycoon

Build a hardware mining company from one GPU rig to a massive industrial data center.

Complete gameplay: procedural 3D environment; animated hardware GPU/ASIC/racks; placement grid; facility expansions; equipment store; live coin earnings; selling coins; electricity and capacity; thermal management; maintenance; 10 contracts; daily rewards; offline mining; local save; simulated fluctuating coin market.

Controls: tap equipment shop, tap free tile to place. Drag to rotate. On PC use right-drag and mouse wheel.

English-only UI. All mined DNCH are fictional in-game points and cannot be redeemed for real tokens or money.

Godot 4.5.2 + Android SDK 35. Original generated textures/icons/audio.
Build with python3 tools/generate_assets.py, then Godot editor import and Android debug export.
This is a full playable offline game loop, but it is not a AAA production title. Physical Android device testing is still required.
