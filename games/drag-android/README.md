# DNCH Drag Racing — Android (0.3 тестова версия)

Автономна Android версия на съществуващата българска DNCH Drag Racing v0.2.

- 402 метра драг, съперник и светофар, физика на сцеплението и въртящия момент.
- Три автомобила, тунинг, ръчни/автоматични скорости, игрови кредити и локални рекорди.
- Бутони за газ и смяна, адаптирани за докосване.
- Всички ресурси се включват в APK; играта работи офлайн.
- Няма покупки или крипто изплащания.

Сглобяване: GitHub Actions -> `DNCH Drag Racing Android APK` -> изтегляне на `DNCH-Drag-Racing-Android-debug` -> `app-debug.apk`.

**Статус:** тестов APK. Възможни са проблеми с управлението и мащаба на някои телефони; нужен е тест на реално устройство. Данните в Android и сайта са отделни.
